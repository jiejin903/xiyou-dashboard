# 服饰运营作战指挥中心 · MVP v0.1

> 服饰运营团队的数字化作战指挥中心 · 统一作战入口

## 一、项目说明

为服饰运营团队搭建的核心作战系统，整合数据监控、项目作战、信息指挥、安全审计四大模块，实现运营工作的标准化、可视化和高效协同。

## 二、文件结构

```
服饰运营作战系统/
├── login.html      # 安全登录页（双重身份验证）
├── index.html      # 作战指挥中心主页（含5大功能模块）
└── README.md       # 本文档
```

## 三、核心模块

### 🛡 安全登录（login.html）
- **双重身份验证**：企微扫码登录 + 动态密码登录两种方式
- **安全提示**：企微身份+设备绑定+IP白名单 三重校验
- **品牌墙**：左侧展示系统定位与核心能力

### 📊 作战指挥中心（index.html）

**5个一级模块：**

| 模块 | 核心能力 |
|---|---|
| **作战总览** | 顶部KPI、Q2 OKR进度、关键预警、七大赛道核心三件事 |
| **数据监控中心** | 30天消耗趋势、赛道占比、偏差自动分析、趋势预测、TOP客户波动 |
| **项目作战室** | 9个在战项目卡，含立项→执行→复盘→归档全生命周期可视化 |
| **信息指挥中心** | 8条智能信息，按紧急度自动排序，支持4种筛选+阅读追踪 |
| **安全审计** | 操作日志、敏感操作二次确认、越权拦截记录（仅运营负责人可见） |

## 四、痛点解决方案

| 痛点 | 系统解法 |
|---|---|
| **信息过载** | 信息中心智能筛选，未读优先、紧急置顶、按类目分组 |
| **优先级混淆** | 全局贯穿红黄绿三色体系（预警条/状态药丸/边框色） |
| **行动聚焦** | 信息→项目作战室→赛道核心三件事 形成闭环 |
| **协作效率** | 项目卡显示负责人/团队/截止时间，点击进入作战室详情 |

## 五、权限管控（演示）

顶部右侧切换角色按钮可体验：

- **运营负责人**：全量数据 · 7赛道 · 可访问全部模块
- **赛道运营**：仅本赛道（女装）数据 · 访问「安全审计」会显示权限锁屏

## 六、技术亮点

- ✅ **纯HTML+CSS+JS**：无外部依赖，秒开
- ✅ **CSS自绘图表**：30天趋势条形图+饼图，无需Chart.js
- ✅ **完全响应式**：PC端/iPad/手机三端适配（断点 768px / 480px）
- ✅ **大屏模式**：右上角⛶按钮一键全屏，适合作战室大屏展示
- ✅ **模拟真实数据**：所有数据均贴合服饰运营业务场景（七赛道+三率+QYT跃迁+新锐拓客）
